# 手順を送る画面の試作

`step-preview.html` は、ひっさんノートの解答を1手順ずつ表示する操作感を確認するための独立した試作です。アプリ本体の `index.html` は変更していません。

- 「まえへ」「つぎへ」で手順を送る。
- 前の手順で書いた数字は残し、今書く数字や線はオレンジで示す。
- 「ぜんぶ みる」で完成した筆算を表示し、同じボタンで手順表示に戻る。
- 数字の手順ボタンから途中に移動できる。
- 「はじめから」で最初へ戻る。
- 四則演算を切り替えられる。例は 72÷3、27＋15、52−28、23×14 の固定例。
- 答えを先に見せない案として、上部の式の答えは最後まで「？」にしている。

任意の数字での計算、入力画面との接続、実アプリへの機能追加は未実装です。
