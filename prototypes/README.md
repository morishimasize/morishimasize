# 手順を送る画面の試作

`step-preview.html` は、ひっさんノートの解答を1手順ずつ表示する操作感を確認するための独立した試作です。アプリ本体の `index.html` は変更していません。

- 「まえへ」「つぎへ」で手順を送る。
- 前の手順で書いた数字は残し、今書く数字や線はオレンジで示す。
- 「ぜんぶ みる」で完成した筆算を表示し、同じボタンで手順表示に戻る。
- 進み具合は小さな点で表示する。小さな点は押させず、操作は大きな「まえへ」「つぎへ」に絞る。
- 「さいしょから」で最初へ戻る。
- 四則演算を切り替えられる。例は 72÷3、27＋15、52−28、23×14 の固定例。
- 答えを先に見せない案として、上部の式の答えは最後まで「？」にしている。

任意の数字での計算、入力画面との接続、実アプリへの機能追加は未実装です。

低学年向けに、ひらがなと演算記号を併記し、ボタンを大きくしています。「まえへ」「つぎへ」は画面下に固定し、最後は「もういちど」に切り替わります。自動で手順は進めません。


## ゲーム性の試作

`game-preview.html`・`game-preview.css`・`game-preview.js` は、今日の3問→ごほうび→シール帳の体験を確認する独立した試作です。公開URLと仕様はルートのREADME「ゲーム性の試作」を参照してください。本体の計算・手順表示は変更していません。


### 手書き版への更新

`game-preview.html` は `handwriting-preview.js`・`digit-reader.js`・`handwriting-preview.css` を使う手書き版に更新しています。採点の前に認識した数字を確認・修正し、ごほうびは絵の段階的な完成です。途中式採点は将来の予定です。現行の仕様・制約はルートREADME「手書き解答と絵が完成する試作」を参照してください。
