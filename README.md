# ✏️ ひっさんノート

iPadで使う、子ども向けの筆算電卓です。たし算・ひき算・かけ算・わり算を、筆算と手順で確認できます。

## 起動と使い方

`index.html`、`steps.js`、`forest-notebook.png`、`icon.png` を同じフォルダに置き、`index.html` をブラウザで開きます。Webサーバーに置く場合も、この4ファイルを同じ階層に配置してください。

1. 「ひとつめの かず」を選び、数字ボタンで入力します。
2. ＋・－・×・÷を選ぶと、「ふたつめの かず」に移ります。
3. 2つ目の数字を入力し、「ひっさんを みる →」を押します。
4. 「つぎへ」で1手順ずつ進めます。「まえへ」で戻れます。
5. 「ぜんぶ みる」で完成した筆算を確認できます。「ひとつずつ みる」で元の手順に戻ります。
6. 「← もどる」で入力画面へ戻ります。入力した数字は残ります。

「ひとつ けす」は選択中の数の末尾を1文字削除し、「ぜんぶ けす」は両方の数を消します。各数は最大5桁の非負整数です。わり算は整数の商とあまりを表示します。0によるわり算と、答えが負になるひき算には案内を表示します。

## ノート風のデザイン

- 両画面に同じ水彩の森・うさぎ・鉛筆の背景を使用。
- 方眼紙、綴じ穴、ピンクのテープをCSSで描画。
- 入力画面は大きな数の選択欄と、5列の数字ボタン。
- 解答画面は「式 → 筆算と手順 → 答え」の順に表示。
- 横幅900px以上の横向き画面では筆算と手順を左右に配置。それ以外は上下に配置。
- 桁数が多い筆算は、数字を潰さず筆算欄の中だけ横スクロール。
- 桁と手順の色を対応させ、位の名前をひらがなで表示。

モックアップ画像を画面全体に貼る方式ではありません。ボタン・数字・手順はHTMLで生成するため、計算内容に合わせて変わります。背景の構図や端末のフォントにより、見本画像とは多少見た目が異なります。

## 主な処理

`calc()` が入力を検証し、`rAdd()`・`rSub()`・`rMul()`・`rDiv()`を呼び出します。`steps.js` の `buildLesson()` が、その計算の全手順と盤面のスナップショットを生成します。`showLesson()` で画面を組み立て、`renderLesson()` で現在の手順だけを表示します。`previousLesson()`・`nextLesson()`・`toggleLessonOverview()` が操作を処理し、`backToInput()` で入力画面へ戻ります。

桁幅は `steps.js` のモデルの `columns`（通常58px）、間隔は12px、行の間隔は70pxです。画面の見た目は `index.html` のCSS末尾「1手順ずつ進める解答画面」から調整できます。

### iPad縦向きの入力画面の余白調整

幅701px以上・高さ850px以上の縦向き画面では、入力ノートを画面の高さに合わせて伸ばし、数字ボタンにも余った高さを配分します。入力欄・演算ボタン・計算ボタンも高さに応じて拡大します。iPhone向けの幅700px以下の表示と、解答画面・横向きの配置は維持します。高さには `svh` を使用し、非対応ブラウザ向けに `vh` を指定しています。画面やエラー案内が収まらない場合は、切り取らずスクロールできます。

### 割り算の筆算記号

割る数の右の曲線はSVG、割られる数の上の横線はCSSの疑似要素で描画します。数字のマスの角丸から独立させ、横線が波打ったり途切れたりする表示を修正しました。記号の線幅は3pxです。

### 解答画面の上部を簡略化

解答画面ではタイトルと「いっしょに けいさんしよう」を非表示にし、上部の「もどる」と計算式（例：23 ÷ 23 ＝ 1）のすぐ下に筆算ノートを表示します。長い式は折り返してノートと重ならない配置にしています。入力画面には従来どおりタイトルを表示します。


### 四則演算の手順送りを本体に実装

- 固定の例だけの試作から、入力した最大5桁の数で動く処理に変更しました。
- 「まえへ」「つぎへ」を画面下に固定し、最後の手順では「もういちど」に切り替えます。
- 上部の式の答えは途中で「？」、最後または「ぜんぶ みる」で表示します。
- 「ぜんぶ みる」は完成した盤面を表示し、「ひとつずつ みる」で直前の手順に戻ります。
- 今書いた数字はオレンジ、計算で見る数字は黄色の背景で示し、説明も1手順ずつ切り替わります。
- 割り算は「たてる・かける・ひく・おろす」を分けます。途中の商の0、あまり、割られる数が小さい場合も扱います。
- ひき算は、連続する0をまたいで10を渡す過程を順番に表示します。
- かけ算は各桁の計算とくり上がりを表示し、複数段の結果をたす過程も桁ごとに表示します。
- 長い筆算は盤面の中でスクロールし、手順で見る場所へ表示位置を合わせます。入力画面から戻った場合も数値は残ります。

検証：四則演算709件で、完成した盤面の答え・割り算のあまり・全手順の桁位置・くり下がりの連鎖・商の途中の0を確認。戻る、進む、完成形から元の手順への復帰、最後からの再スタート、入力範囲の検証も確認しました。試作ページは別途残しています。

ブラウザでも375×667と768×1024の画面サイズで、割り算の手順送り、完成形から元の手順への復帰、連続する0からのくり下がり、掛け算の最後の足し算、入力画面へ戻った際の値の保持を確認しました。iPhone・iPadの実機でのタッチ操作は未確認です。
