# ひっさん★マスター V4

小学生が筆算の仕組み（くり上がり・くり下がり・段階的な計算手順）を視覚的に理解するための学習支援ツールです。

---

## 📱 動作環境

- **主な対象端末**：iPad（iPhone でも動作）
- **形式**：HTML 単体ファイル（PWA対応）
- **操作方法**：タップのみ（キーボード不要）

---

## ✨ 機能

| 演算 | 特徴 |
|------|------|
| ➕ 足し算 | くり上がりをオレンジの小さい数字で表示。桁ごとに手順解説カード付き |
| ➖ 引き算 | くり下がりを「赤い斜線で消す＋右上に新しい数字」で視覚的に表現 |
| ✖️ かけ算 | 部分積をステップカラーで色分けし、右側の解説文を各行に同期表示 |
| ➗ 割り算 | 「たてる・かける・ひく・おろす」をグリッドと手順カードで段階表示 |

### 共通の表示仕様
- 桁ごとの色分け（一の位：青 / 十の位：緑 / 百の位：オレンジ / 千の位：紫 / 万の位：赤）
- 下部に「手順カード」を自動生成し、計算過程を文章で解説
- 入力は最大5桁まで対応

## 🔧 操作方法

1. **数字ボックスをタップ** → 入力対象を切り替え（アクティブな方が黄色枠で強調）
2. **演算子ボタンをタップ** → ＋－×÷を選択。自動的に2つ目の数字入力へフォーカス移動
3. **キーパッドで数字を入力** → 各数字は最大5桁まで
4. **「けす」ボタン** → 現在の入力対象の末尾1文字を削除
5. **「全て消す」ボタン** → 両方の数字を一括クリアし、1つ目へフォーカスを戻す
6. **「＝ ひっさんを表示」ボタン** → 筆算グリッドと手順解説を表示

> **自動表示にしていない理由**：かけ算・割り算の手順解説が複雑なため、数字を全部打ち終えてから表示させる方が子どもにとってわかりやすいため。

## 🧮 各演算の特殊な仕組み

### 足し算
- くり上がりを右から左へ1回走らせて `carryIn` / `carryOut` / `colSum` を配列で管理
- くり上がり数字はオレンジの小セル（`gscBox()`）で表示

### 引き算
- `borrowNeeded[]`（くり下がりが必要な列）と `lentTo[]`（くり下がりを渡した列）の2配列で連鎖くり下がりを管理
- くり下がりは `gvBorrow()` で元の数字に赤い斜線を引き、右上に `(元の数字－1)` を重ねて表示

### かけ算
- かける数（n2）の各桁ごとに部分積を求め「手順1・手順2…」として積み上げる
- `shift` 変数で桁ずれを管理し、ずれた部分は空セル（`ge()`）で表現
- 2桁以上のかけ算の場合のみ、最後に合計手順カードと下横線を追加

### 割り算
- `qStart` で商が立つ桁を先に特定してから `steps[]` を左から順に構築
- L字型グリッドレイアウト（上と左の太線）で商を上に・割られる数を右に配置
- 各ステップで「かける→横線→ひく」の3行を繰り返し
- あまりがある場合はあまり専用の手順カードを追加
