# ✏️✨ ひっさん★マスター V5

iPad のホーム画面に追加して使う、筆算学習用 PWA アプリです。  
たし算・ひき算・かけ算・わり算の「くり上がり・くり下がり」を、ステップごとに視覚的にわかりやすく表示します。

---

## ✨ 機能

| 機能 | 内容 |
|------|------|
| 四則演算の筆算表示 | ＋ / － / × / ÷ の筆算をリアルタイムで生成 |
| くり上がり表示 | たし算の各桁のくり上がり数を小さく表示 |
| くり下がり表示 | ひき算で「借りた」桁を取り消し線＋修正値で表示 |
| 部分積の手順表示 | かけ算の各桁の計算を色分けしてステップ表示 |
| 割り算の筆算 | たてる・かける・ひく・おろす の4ステップを色分け表示 |
| 手順解説カード | 各演算の計算ステップをひらがなで丁寧に解説 |
| 画面切り替え | 計算後は入力欄を隠し、結果に集中できる画面へ切り替え |
| 「けいさんにもどる」ボタン | 計算結果から入力画面にワンタップで戻れる |
| エラーメッセージ | 未入力・ゼロ除算・負の結果（ひき算）を検知して案内 |
| 背景画像テーマ | 入力画面：文房具柄 / 解答画面：森・木の絵（切り替え対応）|

---

## 📱 使い方

1. 数字ボタンをタップして「1つ目の数」を入力
2. 演算子（＋ / － / × / ÷）を選択
3. 「2つ目の数」を入力
4. **「＝ ひっさんを表示」** を押す
5. 筆算と手順解説が表示される
6. **「← けいさんにもどる」** でやり直せる

## 🎨 デザイン仕様

### 背景画像

| 画面 | ファイル | 内容 |
|------|---------|------|
| 計算入力画面 | `keisan.PNG` | 文房具・定規・鉛筆柄（base64埋め込み済み） |
| 解答画面 | `kaitou.PNG` | 森・木・動物のイラスト（base64埋め込み済み） |

- 画面切り替え時に `body.answer-mode` クラスの付け外しで背景が切り替わる
- 背景画像は HTML 内に base64 で埋め込み済み（オフライン・PWA完結）
- `background-position: center 20%` でロゴ上部のイラストをトリミング

### カラー（`:root` セクション）

| 変数名 | 値 | 用途 |
|--------|----|------|
| `--color-bg` | `#FFFDF0` | 背景色（フォールバック） |
| `--color-main` | `#FF8BA7` | メインカラー（答え・ボタン等） |
| `--color-sub` | `#A0E4FF` | サブカラー（もどるボタン等） |
| `--color-text` | `#5F4B32` | テキスト色 |
| `--color-focus` | `#FFF9C4` | 選択中の数字ボックス背景 |
| `--bg-keisan` | base64 URL | 入力画面背景画像 |
| `--bg-kaitou` | base64 URL | 解答画面背景画像 |

### 透明度設計

| 要素 | 背景 | 備考 |
|------|------|------|
| 入力カード全体（`.card`） | 透明 | 背景画像をそのまま表示 |
| 数字ボックス（`.num-box`） | `rgba(255,255,255,0.82)` | backdrop-filter あり |
| キーパッドボタン（`.key`） | `rgba(255,255,255,0.82)` | 半透明白 |
| 筆算グリッド（`.hp-grid-wrap`） | `rgba(255,255,255,0.82)` | backdrop-filter あり |
| 手順カード（`.step-card`） | `rgba(255,255,255,0.78)` | backdrop-filter あり |
| 解答エリア全体（`.hp`） | 透明 | 背景画像をそのまま表示 |

### サイズ（iPad向け大型設定）

| 要素 | クラス/ID | 設定値 |
|------|----------|--------|
| アプリ全体幅 | `#app` | `max-width: 800px` |
| ロゴ上余白 | `#app` | `padding-top: 30vh`（入力時） |
| 数字入力ボックス | `.num-box` | `160×80px` / フォント `48px` |
| 演算子ボタン | `.op-btn` | `70×70px` / フォント `36px` |
| キーパッドボタン | `.key` | 高さ `80px` / フォント `38px` |
| 計算ボタン | `.calc-btn` | 高さ `80px` / フォント `28px` |

## ⚙️ 技術仕様

### 標準設定（削除・変更禁止）

```html
<html lang="ja">
<meta charset="UTF-8">
<meta name="robots" content="noindex">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
```

- **PWA対応**：ホーム画面からフルスクリーンで起動
- **ピンチズーム禁止**：`user-scalable=no` で誤操作を防止
- **検索エンジン非公開**：`noindex` で外部公開なし
- **フォント**：`Hiragino` / `Meiryo` でiOS日本語表示最適化

### 主なJS関数

| 関数名 | 役割 |
|--------|------|
| `calc()` | 入力値を検証し、各演算関数を呼び出す。`body.answer-mode` を付与して背景切り替え |
| `backToInput()` | 結果画面→入力画面への切り替え。`body.answer-mode` を除去 |
| `rAdd(n1, n2)` | たし算の筆算グリッドを生成 |
| `rSub(n1, n2)` | ひき算の筆算グリッドを生成 |
| `rMul(n1, n2)` | かけ算の筆算グリッドを生成 |
| `rDiv(dvd, div)` | わり算の筆算グリッドを生成 |
| `makeStepCard()` | 手順解説カード（ひらがな表記）のHTMLを生成 |
| `setHPFull()` | 筆算グリッド＋手順カードをまとめて `#hp` に描画 |

## 🔧 保守・微調整ガイド

### 背景画像のロゴ位置を調整したい
`background-position: center 20%` の `20%` を変更してください。数値を大きくすると画像が上にずれます。

### 入力カードの位置（ロゴ下の余白）を調整したい
`#app` の `padding-top: 30vh` の値を変更してください。

### 半透明度を変えたい
各要素の `rgba(255,255,255,0.82)` の最後の数値（0〜1）を変更してください。1に近いほど不透明になります。

### 手順カードの色を変えたい
`makeStepCard()` 内の `border-left` カラーは各演算ステップの色（`STEP_COLORS`配列）に連動しています。

### サイズを変えたい
各クラスの `height` や `font-size` の数値を変更してください。

### 入力桁数を変えたい
`pressNum()` 内の `n1str.length < 5` の `5` を変更してください（現在は最大5桁）。
